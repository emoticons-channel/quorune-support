サポート

対象製品: Quorune Rename、Quorune PDF

公開者: エモティコンズCH

メール: emoticons.channel@gmail.com

お問い合わせには、製品名とバージョン、Windowsのバージョン、エラー内容、再現手順を記載してください。機密文書、実運用データ、PDFパスワード、プロダクトキーは送信しないでください。

お問い合わせ前の確認

  1. Windows Updateを適用してPCを再起動してください。
  2. 入力ファイルが別のアプリで開かれていないことを確認してください。
  3. 出力先の書き込み権限と空き容量を確認してください。
  4. Quorune PDFでは、PDFが破損していないことと、解除時のパスワードが正しいことを確認してください。
  5. Quorune Renameでは、実行前に赤色の競合メッセージを解消してください。

管理者権限は不要です。実行のためにWindowsのセキュリティ機能を無効化しないでください。

Support

Products: Quorune Rename and Quorune PDF

Publisher: エモティコンズCH

Email: emoticons.channel@gmail.com

Include the product name and version, Windows version, exact error message, and steps to reproduce. Do not send confidential documents, production data, PDF passwords, or product keys.

Before contacting support

  1. Install Windows updates and restart the PC.
  2. Confirm that the input file is not open in another app.
  3. Check write permission and free space at the output location.
  4. For Quorune PDF, confirm that the PDF is valid and that an unlock password is correct.
  5. For Quorune Rename, resolve red conflict messages before applying changes.

The apps do not require administrator rights. Do not disable Windows security features to run them.
